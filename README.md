This is the academic project of CPSC_304 in UBC.
Authors: Mumen Asdo, Weili Bai, Jinoh Kim
This project simulates the record management system of a military base:
1. Soldiers' information, including their combat record, duty, assigned weapons etc.
2. Budget to the military base.
3. Different buildings i.e training fields, storages, barracks etc.

Able handle insertion/deletion/projection/join/relational division.
Oracle SQL account required.
